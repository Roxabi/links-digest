# roxabi-intel

Discord links digest with frontmatter MDs and dynamic gallery.

## Overview

Discord links digest: fetches pages from links shared in a Discord channel, converts each into a frontmatter markdown file, and renders a dynamic gallery. Run manually via `make digest` / `make build` / `make deploy`. Deploys to Cloudflare Pages.
